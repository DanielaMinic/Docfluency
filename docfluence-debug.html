Introduction to the Digital Archive

The Digital Archive enables easy viewing and organization of documents that are located in a folder structure. The application contains basic items, ie. tabs necessary for uploading, organization and further distribution of documentation. These items form the basis of the functionality of the Digital Archive application.


Document Groups

A Document type group is a collection of Document types for better organization and preview. A Document type group can also have its Parent group. If the Group is not used, the status "inactive" is assigned to it.


Document Types

The document type defines the name and array of index data available for viewing and optional searching. Document types are digital representations of actual analog documents that exist in a folder structure. On the other hand, index data is used for easier finding of documents stored in the digital archive. Document types display their unique name made up of the partent group (if any), the document type group and the document type name itself. If the document type has not been deleted and is not in use, it is assigned the status "disabled" and remains displayed among the other document types, but will not appear in the document search.


Index Data

The details of one type of document contain its index data, which can be of various types - text, number, values ​​from the lookup, date, yes/no confirmation or counter (sequence). When entering documents, the selected type of index data must have its value from the lookup (if the type of index data is a value from the lookup). Index data can be:

Searchable - users of the application will be able to search the document through this index data;

In list - this index data will be displayed in the list of requested documents;

Publicly visible - after the search is completed, users of the public portal will be able to see this index data next to the document;

Naming index data – data that will form the name of the ordered document;

Technical index data - it is not visible to all system users, it is not possible to add or change it without specific permission;

Index data can also be marked for transliteration into Cyrillic, if the transliteration of data from the folder structure is necessary.


Lookups

The lookup provides information about the structure, content, and appearance of the data file. Users are advised to search the lookups before entering or modifying data. One lookup contains definitions of different record types and key/value pairs used to identify the entered metadata.

It is necessary to predefine the lookups and enter them into the database. These lookups can be accessed, viewed, its key/value pairs can be added and changed through the application. Lookups can be assigned "inactive" status and as such will not be able to be used as metadata of a document type. In addition to the name, the lookup optionally contains its own description, which is an additional clarification of the lookup itself.


DocumentsSubjects

Documents and their preview are the core of the Digital Archive application. Each document belongs to exactly one document type. A document in a digital archive is a series of index data defined by the appropriate type of document, a series of images adapted for preview and a series of original images.

On this page, it is possible to search for the documentation of the digital archive

The search is performed by selecting the appropriate fields

By selecting a document type, additional data of that document type is loaded - index data marked searchable

Each document type carries its own specific index data

By selecting and entering one of the index data, documents are filtered

By clicking on the "Search" button, a list of documents of that type filtered by the entered index data is loaded

By clicking on the "Details" button, the details of certain documents of that type are opened


Users

All users who have logged into the application at least once are registered in a unique list and their details are available for viewing with certain rights. Internal users have their own username, email address and roles assigned to them. One user can have multiple roles. In the user details, you can see the time of the last login, as well as add and remove roles.


Roles

When logging in for the first time, the new user is assigned an automatic role with which he can use the system. Existing roles are assigned by the administrator to users depending on the rights that a particular user has. All existing roles are entered in a unique list and permissions related to the role can be added or removed by the administrator. The role can also be deleted with certain permissions.
